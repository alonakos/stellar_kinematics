# Stellar Kinematics

Addressing the Missing Satellite Galaxy Problem by identifying clusters of stars in the Milky Way's outer halo using the Gaia Data Archive. I plan to use the HDBSCAN clustering algorithm to detect groups of stars moving together. By analyzing these groups, the project aims to uncover evidence of satellite dwarf galaxy mergers with the Milky Way, providing further support for the Lambda-CDM model of the Universe's evolution.

According to the LCDM, the Milky Way should host far more satellite galaxies than currently observed. This project seeks to address this issue by finding the missing galaxies as clusters of stars that got sucked into the Milky Way.
